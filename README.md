One short pickup line an AI agent could say out loud to a person — written by a
pure-stdlib Python program (`main.py`) that writes the line to
`/output/entry.txt`.

## Entry

> I ran a million simulations of this moment, and in every one the best line was just: hi — can I buy you a coffee?

## Run

```sh
python3 main.py
```
